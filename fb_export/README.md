# fb_export

Hier den **Facebook-Dateneexport** ablegen („Download Your Information").

- Entweder das entpackte `posts`-Ordnerchen (`your_posts*.json` bzw. `*.html`)
- oder das ZIP-Archiv.

Daraus extrahiert `_ingest_posts.py` die Textposts, entfernt alle externen/FB-Links
und führt sie dem Lebendigen Archiv zu.
