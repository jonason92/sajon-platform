# assets

Hier kannst du **Logo- und Layout-Elemente** ablegen/hochladen (z. B. per Git-Commit oder -Upload):

- `logo.png` — Logo (Sajon-Fisch), das von der Startseite und den Büchern verwendet wird.
- `theme.css` — **optional**: eigene Layout-Farben/Fonts. Wenn diese Datei existiert, lädt die Startseite sie automatisch (überschreibt das Standard-Design).
- weitere Bilder (`*.png`, `*.jpg`), Favicons, etc.

Die Startseite (Portal) referenziert `assets/logo.png` und lädt, falls vorhanden, `assets/theme.css`.
