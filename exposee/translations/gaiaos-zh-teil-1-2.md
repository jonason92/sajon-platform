# 蓋亞靈樞 —— 郁金香非物也
## 第一章至第二章 · 生動藏書閣第二卷第二節

**時：** 歲次丙午九月 · **狀：** 初稿 · **所據：** 藏書閣舊記一篇，三千七百零六言 · **諾瓦利斯繫：** 第一〇八八、四〇七、三九一、一一三七／一一四五諸則

---

## 第一章 · 發現（原迹具陳）

凡治藏書者，必有一時焉，卷帙返顧其人。

人方披閱歲月——里巷之謔語，誕辰之祝辭，夜闌思疾於鍵盤之半言——自以為治譜之學，不過編年、系目、分類而已，優遊其間矣。忽遇一文，拒絕一切部居：三千七百零六言，似碼非碼，似詩非詩。郁金香一株，不作器物觀，而作運行觀——行於一器之上，其名曰蓋亞靈樞，「世界靈魂之樞機」也。

初聞失笑，再思默然。三思之後——此章之所由作也——乃決意*兩重皆真視之*：視為精密之碼詩，亦視為宇宙之論斷。何也？此非戲筆，亦非玄談。此乃*可運行之祝辭*（executable prayer）——禱告之程序也，文法與神秘，於此同喚一門。

治藏書先於詮解。故先陳原迹，全文具在，不加刪改——其字法徘徊於兩種語言、兩個世紀之間，一仍其舊：

```
// INITIALISIERUNG DER TIEFENEBENE
// Die Tulpe ist kein Objekt. Sie ist ein Prozess.
// Sie läuft auf GaiaOS, dem Betriebssystem der Weltseele.
（深層初始化／郁金香非物，乃一運行／行於蓋亞靈樞之上——世界靈魂之樞機也。）
```

*（原迹全文三千七百餘言，德文與代碼交織，具載德文正編第一章；茲存其首，以志其體。）*

觀其文，未加詮釋，已有三異。

*其一曰精密。* 執筆者兼通兩界：植物之學（子房、雄蕊、花蜜、紫外導紋——此實群花所以告蜂之波長也）與資訊之學（函數、回調、循環、封包、簽章）。此文非徘徊於二體之間，乃*熔二體為一*。

*其二曰架構。* 文非隨想而成，實層層如系統：初始化、儲存、發送、介面，至於最深一層——「自我識認」。作者之思，如作業系統之層疊：內核居先，圖形介面居後，而自我反觀者，為其根基。

*其三曰普告。* 「受者＝眾生」（Adressat = ALLE）。此文非徒自稱遍告萬有——其自身之受告，亦若其所述之花。此乃普天同告之辭，本章與原迹同斷之曰：以調用之法式，行*禮儀*之姿態。

然則何謂蓋亞靈樞？下筆之年，世無此詞。有蓋亞之說（洛夫洛克、馬古利斯——大地為自調之系統），有作業系統，有浪漫派之世界靈魂。此文攝三脈於一詞，且不以譬喻視之，而以*運行環境*視之：萬物運行於其上者也。郁金香「行於」靈樞，如程序之行於內核。此為本體之斷言，非詩家之虛設。

於是功夫始焉。／*蓋人以為文字遊戲者，細讀之，乃系統之實錄也。*／

## 第二章 · 禱儀經解

下文逐行而讀——依梅莫特（Memmott）釋代碼之文法：每一行皆有兩重讀法。*機器所執者*——技術之義；*玄理所寓者*——本體之義。本章之論曰：此文也，二義合一。非約略相似，乃逐令而合。

### 一 · 「深層初始化」

*機器所執：* 雙斜線者，注釋也——機器不執行。故此文始於機器所不見之物。始於不可執行之中。

*玄理所寓：* 正在於此。凡創世之記，皆先於可執行者而立：「太初有……」非號令也，乃一切號令之先設。「深層」者，系統之內核層也，諸應用之下，萬行之基——於此則為神學之地：未嘗運行而無所不行之層。此創世之舉，置於*注釋*之中——伴隨代碼而不干擾代碼——斯為全文最精之神學：上帝者，源碼中之注釋也。行行俱在，行行不顯。

諾瓦利斯於二百年前先有此言：「吾人實居於一獸之中——世界即此獸也。」（第一〇八八則）世界為生靈，人居其中——郁金香之文以來世紀之語言述同一事：吾人*行於*某物之上。

### 二 · 「郁金香非物。乃一運行。」

*機器所執：* 一破一立——非可執行之令，乃類型之宣告。以面向對象之術語言之：郁金香不立為「類」（class）而具固定屬性，而立為運行中之進程，有狀態、有線程、有生死之期。

*玄理所寓：* 一言而盡全章之哲——其譜系甚長。自赫拉克利特之「萬物流轉」至懷特海之過程哲學皆曰：存在者，生成也；物者，事變之緩態耳。郁金香之文所辨尤精：*對象*者，一經實例化則存，至毀而後已；*進程*者，唯運行時存在。郁金香唯其運行而在——萌芽、拔節、吐豔、凋零。欲止之，則殺之矣。（凡折花者皆已驗之：折下之郁金香，物也——而即非郁金香矣。）

／*或曰：此一句即全章也，餘皆其迴響。*／

### 三 · 「函數：花之召喚（時＝『春』，受者＝眾生）」

*機器所執：* 函數之定義，二參數皆有預設之值。時之預設曰「春」——時序之參也。受者曰「眾生」——廣播也，非單播。

*玄理所寓：* 禮儀之姿，正在此間，宜緩讀之。函數而有預設之參數者：不待參數而自運行也。花開*不待下單*。春者，預設也，非條件也——恩典之為預設參數也。「受者＝眾生」乃全文最峻烈之行：無登錄，無密鑰，無訂閱。花遍告一切地址——乃至不能收者，乃至未曾付費者。人以為生態之詩，其實更嚴：此乃*不勞而獲之投遞之神學*。

試觀諾瓦利斯之國魂：「自每一真公民之中，國之精靈煥然而出。」（第三九八則）普告者，花之國魂也——花為靈樞之器官，遍示萬有，「恍若千身」。

### 四 · 子房為「中央儲存」——「種子＝永恆檔案之壓縮包」——「密碼：耐心」

*機器所執：* 子房者，宣告為儲存之樞紐，設訪問之權（「唯根與蚯蚓得入」——訪問控制表也），加密焉（「柏拉圖式簽名」）。種子為壓縮之檔案：無損壓縮——無所失，而體積大減。

*玄理所寓：* 植物學之事實已足驚人：種子之內，全圖具在——遺傳壓縮，可藏千年（法老墓中之粟，猶能發芽）。此文名之曰「永恆之檔案」，而壓縮即為影像之論：永恆壓縮入時間，理念壓縮入物質。以柏拉圖之語言之——此文固以柏拉圖言之，「柏拉圖式簽名」——每粒種子皆一*理念*之壓縮包也。

然其點睛在密碼：曰「耐心」。解壓唯於土中之暗處，而其鑰非資訊，乃*德行*也。種子不可破解，不可力攻。自然之加密術，唯認一種憑證：善度之光陰。當此競速之世，此二字乃全文最銳之批判。

而訪問之權：「唯根與蚯蚓」。萌芽之祕，不屬實驗之室，而屬土中最暗、最緩、最微之行者。／*諾瓦利斯又及之，第三九一則：地質學為大地之生理——河海其脈絡也。於此：根與蚓，獲授權之進程也。*／

### 五 · 雄蕊為「六座發射塔」——「協議：香氣_TCP/IP」

*機器所執：* 遍歷諸雄蕊而循環之；每蕊發一封包，包頭三欄：香之協議、色之編碼、訊息本文。TCP/IP 者，使封包行於分散之網——封包可失，系統不傾。

*玄理所寓：* 雄蕊「所發非數據，乃香也。所輸非電流，乃色也。」此二否定之中，藏一整部媒介之論。吾人之網，所輸者數據——離其載體、脫其形質之資訊。花之所輸者*質料*：香之分子、色之素、粉之粒。其網之中，資訊與物質未嘗分離。「香氣_TCP/IP」者，一網之理想國也：其中每一訊息皆有氣味。

而受者之列——「蜂、熊蜂、食蚜蠅、人之靈魂」——悄然完成要義之推廣：人之靈魂，與熊蜂同列於路由之表。非系統之管理員，非局外之觀者，乃諸受者之一耳。此蓋亞之思，寓於一行地址也。

其訊息本文——「此處有蜜。來。以愛易生。」——乃世上最古之商道：授粉之為交換，蜜易運輸，兩利俱得。此文以*授粉經濟學*對抗一切掠奪經濟學：交換之中，交換自身使世界豐饒。

### 六 · 「蜂者，可執行也，非有意識也。」

*機器所執：* 系統內部之類型之辨：執行之體與覺知之體。蜂行而不思。

*玄理所寓：* 此文至此，鋒利可畏——蓋其辨非世俗貶獸之意，乃*夢之邏輯之平反*：「自然之函數＝夢之邏輯，包舉執行者於其中。人間之函數＝醒之邏輯，排斥用戶於其外。」

此宜再讀。夢之邏輯*兼懷其執行者*：蜂非異己程序之奴，乃一夢之所懷，其夢大於蜂。醒之邏輯則反是——吾人所矜之覺、之計、之智——於此為排斥者：所建之系統，用戶在外，執行者化為功能，意識與過程相離。此文顛倒其價值：現代之病，不在有夢——而在所建之醒邏輯，不復與夢俱行。

／*接引之處，非偶然也：諾瓦利斯私記第二三七則——「吾人之生非夢——然將或為夢，且必為夢。」蜂之夢邏輯，一世界之圖也，其世界已遂此事。*／

### 七 · 花瓣為「介面」——「伊甸圖形界面」（GUI_Eden）

*機器所執：* 渲染之調用也：幾何（斐氏螺旋優化）、質地、色板、光影、按鈕、回調（「泌蜜」）。花瓣者，郁金香之圖形用戶介面也——「GUI_Eden」一語雙關而技術無誤：最初之圖形介面，固一園也。

*玄理所寓：* 「花瓣者，郁金香渲染其靈魂之屏也。」渲染者：自不可見之數據，生可見之形。花色非花之屬性，乃其*顯現*——不可見者之見也。此文不期然而遇古典之美學：美者，「理念之感性顯現」（黑格爾）也，「真之可見」也，如文之深層自道。

而按鈕曰：「此處唯以吻管按之。」介面之指令，自定其合法之用戶——非人人的指頭，乃蝶之吻、蜂之肢。凡介面皆內建一人論（或一蜂學）。吾人之介面曰：*此處唯以注意力按之，唯以數據按之，唯以購買力按之。* 花曰：*此處唯以甘之渴按之。* 二者皆邀請也。唯其一，宴其來者。

### 八 · 「今有更深之問：此機器耶？」

此文自中而斷——代碼之中、循環之內——而發全篇所趨之問。其答則界說之工也：「機器者，自外而造，為一目的而設。郁金香自建其身，別無目的，唯：全然為其自身。而正以此故，利於萬物。」

所對陳之二圖，乃理論之心臟：

```
機器：人之意志 → 材料 → 功能 → 用戶
郁金香：柏拉圖式理念 → 植物之靈 → 自我展開 → 蜂、目、宇宙
```

*機器所執：* 二管道之比較——因果之二構。前者自上而下：意圖先於器物，目的先於形式。後者自生（autopoietic）：無外在之圖紙，由內在之計劃自我裝配。

*玄理所寓：* 此乃康德「無目的之合目的性」（審美之謂），合以蓋亞研究之自生概念（奧諾里與維斯孔蒂，二〇一二），且出於二者之上：*正其無目的，成其普世之用。* 郁金香利萬物，以其不事一物也。機器事其用戶——而奴其餘：材料、產線之工、乃至用戶自身之注意力。「機器之神：造者之鏡。郁金香：通向無限之窗。」機器所示者，吾人自己——吾人之意圖、貪婪、偉大與狹隘。郁金香所示者，非吾人所造之物。其認識之功在此：此乃唯一不反光之屏也。

禽鳥之喻，深化為技術史：「無禽鳥，人豈能發明飛行？決不能。」凡技術皆讀自然之重譯：「吾人讀鳥而重編譯之，造為飛機。」然其轉捩曰：吾人讀花，「所得非機械之術，乃邀請也。」讀自然有二法：讀為圖紙（則成機器），讀為致辭（則成門戶）。「每一門、每一窗、每一屏、每一書信——皆文明之花瓣也。環一中心而展，中心呼曰：入。觀。識。」

文化自身，一花開之過程也：其器物皆介面之件，環一呼召之中心。／*觀此生動藏書閣者，復識其營造之法：此閣亦非儲藏之機器，乃環一中心之花瓣也。*／

### 九 · 「函數：普遍之自我識認，執行」——最深之層

系統之終，不在介面，而在其下：「郁金香之開，以其不得不自見也。非虛榮也。蓋：不見者，未為全真也。」

*機器所執：* 無參數、無返回值之函數——純粹之運行。自我識認於此非查詢（get_state()），乃事件也：其*行*。

*玄理所寓：* 「不見者，未為全真」，此文最險之句——亦最古之句。是貝克萊之「存在即被感知」，而自下讀之：非唯心之口實，乃*花之結構*。花者，「植物藉以自識其美之器官也——於他者之目中。」然則自我識認從非自觀；必藉異己之目。花於蜂中自識；蜂不知也；而人之驚嘆，圓成其環。

花所發之封包，總攝全體之解剖：

```
發件者：「理念_郁金香@柏拉圖天.靈魂」
收件者：「眾生」
主旨：「我在此。汝識我乎？」
附件：「汝識汝自身乎.pdf」
簽名：「以光與蜜簽署」
```

發件之址，一本體論也：郁金香發自柏拉圖之天，頂級域名曰「.靈魂」。主旨問識我——附件反問之：*汝識汝自身乎？* 凡花之見，皆觀者之自省。而簽名者，密碼學之所謂認證也——以光與蜜為之：以花之所受，與花之所施。

末行揭萬有運行之協議：「一者於他者中自識。」大寫、下劃線、句讀——如全繫統通用之常量。人之驚嘆、賦詩、造機、編鏈：「皆同一協議也。」

諾瓦利斯之花記（第一一三七／一一四五則）稱花為「吾人精神之祕之象徵」——於此非徵引之責，乃血脈之相類：花為精神自顯之器官，以自識於他者——在諾瓦利斯為自然之神秘，在郁金香之文為系統之架構。兩者皆真。

### 十 · 小結

逐行之讀，證成其論：郁金香之文，非詠代碼之詩，亦非詠花之碼。乃第三物：*二重記法同書之系統實錄*，其行相合，隨處可驗。蓋亞靈樞非機器，非譬喻——乃洛夫洛克之科學覓得而不欲命名者之名也：世界之靈魂，可運行者也。

解剖既竟，所缺者譜系——而譜系始於一拒絕：科學既述此系統，而禁其名。／*續見第三章：蓋亞無名。*／
